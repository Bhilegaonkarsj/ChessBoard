# ♟️ JavaFX Chessboard

A visually interactive chessboard built using **JavaFX** with complete chess piece logic and GUI handling.

> ✅ Inspired by a real interview question!

---

## 🎯 Features

- 🟦 **8x8 Chessboard GUI** using JavaFX `GridPane`
- ♟️ All standard chess pieces implemented (`King`, `Queen`, `Bishop`, `Rook`, `Knight`, `Pawn`)
- 👆 Click to select and move pieces
- 🔁 Turn-based movement (White vs Black)
- ✅ Valid move checking based on individual piece logic
- ⏱️ **Timer per player**
- ♔ Unicode-based chess piece rendering
- 🧼 Clean OOP structure (abstract class for `Piece`, subclass for each type)
